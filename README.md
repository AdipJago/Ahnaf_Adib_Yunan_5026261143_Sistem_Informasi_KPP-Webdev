# Ahnaf Adib Yunan — Web Developer Portfolio

Landing page personal portfolio dengan tema Web Developer.

## Deskripsi
Website ini dibuat sebagai proyek landing page menggunakan HTML5 dan CSS3 murni. Halaman menampilkan profil singkat, minat di bidang web development, pengalaman organisasi, proyek, serta tautan portofolio.

## Teknologi
- HTML5 (semantic elements)
- CSS3 (layout, responsive design, hover effects)
- Google Fonts (Manrope dan DM Mono)

Tidak menggunakan JavaScript maupun framework CSS.

## Struktur
- `index.html` — struktur dan konten halaman
- `style.css` — seluruh styling dan responsive layout

## Peserta
Ahnaf Adib Yunan

## Menjalankan
Buka file `index.html` melalui browser.
